```
╔════════════════════════════════════════════════════════════════╗
║                   CASHIER QUICK REFERENCE                      ║
║                                                                ║
║  Role: Point of Sale (Customer Transactions)                  ║
║  Access: POS Terminal                                         ║
╚════════════════════════════════════════════════════════════════╝

KEY RESPONSIBILITIES
═══════════════════
  ✓ Process sales quickly & accurately
  ✓ Accept payments (Cash/Card/Credit)
  ✓ Maintain till accuracy
  ✓ Provide excellent customer service
  ✓ Handle returns & issues

MOST USED FEATURE
════════════════
  POS             → Point of Sale terminal

DAILY WORKFLOW
══════════════

  MORNING:
  1. Log in
  2. Collect till (starting float)
  3. Test barcode scanner
  4. Test receipt printer
  5. Check POS operational

  DURING SHIFT:
  1. Greet customer warmly
  2. Scan items quickly
  3. Process payment
  4. Give receipt
  5. Thank customer

  END OF SHIFT:
  1. Stop accepting sales
  2. Count till cash
  3. Reconcile with system
  4. Report variances
  5. Clock out

POS TRANSACTION FLOW
════════════════════

  STEP 1: SCAN ITEMS
    • Scan barcode OR enter SKU
    • Product appears with price
    • Verify correct item
    • Enter quantity if >1
    • Click "Add to Sale"
    • Repeat for each item

  STEP 2: REVIEW CART
    • Check all items correct
    • Verify quantities
    • Verify unit prices
    • See subtotal

  STEP 3: SELECT PAYMENT
    • Click "Checkout"
    • Choose payment method:
      💵 CASH
      💳 EFTPOS (Card)
      📋 CREDIT ACCOUNT
    • Enter amount/account

  STEP 4: COMPLETE
    • Click "Complete Sale"
    • Receipt prints
    • Cash drawer opens (if cash)
    • Sale number shown
    • System updates stock

PAYMENT METHOD GUIDE
═══════════════════

  💵 CASH
    1. Select CASH
    2. Enter amount given
    3. System shows change
    4. Verify change amount
    5. Give change to customer
    6. Keep receipt

  💳 EFTPOS/CARD
    1. Select EFTPOS
    2. Confirm amount
    3. "Please insert/tap card"
    4. Wait for approval
    5. If approved: Complete
    6. If declined: Try different card

  📋 CREDIT ACCOUNT
    1. Select CREDIT ACCOUNT
    2. Enter account number
    3. System verifies account
    4. Confirm customer name
    5. Click Complete
    6. Invoice created

CUSTOMER SERVICE TIPS
═══════════════════
  ✓ Greet with smile: "Hi, how are you?"
  ✓ Scan carefully: One item at a time
  ✓ Be patient: Don't rush customer
  ✓ Answer questions: "Is this right?"
  ✓ Bag neatly: Pack items carefully
  ✓ Count change: Loud & clear
  ✓ Thank warmly: "Thank you, come again!"

HANDLING ISSUES
═══════════════

  Barcode Won't Scan?
    1. Check barcode for damage
    2. Clean barcode
    3. Try again
    4. Manual search if needed

  Item Not Found?
    1. Try different barcode
    2. Search by name
    3. Ask customer
    4. Call manager if unknown

  Insufficient Stock?
    1. POS shows warning
    2. Enter available qty
    3. Inform customer
    4. Complete sale
    5. Alert warehouse

  Customer Wants Discount?
    1. Click "Apply Discount"
    2. Get manager approval
    3. Enter discount %
    4. Complete sale

  Customer Returns Item?
    1. Check receipt date
    2. Verify item condition
    3. Click "Process Return"
    4. Enter sale number
    5. Select item
    6. Process refund
    7. Give credit

TILL RECONCILIATION
═══════════════════

  END OF SHIFT:
    1. Stop accepting sales
    2. Count all cash
    3. Record amount
    4. Click "Reconcile"
    5. System shows expected
    6. Compare actual vs expected
    7. Report variance
    8. Confirm

  VARIANCE CHECK:
    ✓ Matches? → Click Confirm
    ⚠️ Short? → Investigate
       • Discounts?
       • Voided sales?
       • Returns?
       • Math errors?

QUICK TIPS
═════════
  • Use barcode scanner (faster than typing)
  • Type SKU quickly if barcode missing
  • Count change OUT LOUD
  • Never leave till unattended
  • Always give receipt
  • Report till variance to manager
  • Be friendly but efficient

KEYBOARD SHORTCUTS
══════════════════
  Enter        → Add Item to Sale
  Backspace    → Remove Item
  Tab          → Move to next field
  Cmd/Ctrl+P   → Print Receipt
  Cmd/Ctrl+S   → Complete/Save Sale
  Escape       → Clear/Cancel

PROBLEM SOLUTIONS
═════════════════

Card Declined?
  └─→ Check expiry date
  └─→ Try different card
  └─→ Or use cash

POS Won't Respond?
  └─→ Wait 10 seconds
  └─→ Refresh page
  └─→ Try again
  └─→ Call IT if continues

Printer Won't Print?
  └─→ Check paper
  └─→ Check connection
  └─→ Restart printer
  └─→ Call IT if needed

Till Doesn't Match?
  └─→ Recount cash
  └─→ Check for discounts
  └─→ Check for voids
  └─→ Report to manager

═══════
  Manager/Supervisor: [Contact]
  IT Support:         [Contact]
  Shift Lead:         [Contact]
```
